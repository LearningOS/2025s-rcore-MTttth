## 功能总结
### 重写了系统调用 ```sys_trace```，支持以下三类操作：

1. 读取操作（trace_request = 0）：从当前任务的 id 地址处读取一个字节的无符号整数。先是将用户虚拟地址映射到物理内存空间，最后在物理内存进行数据读取。
2. 写入操作（trace_request = 1）：将 data 的最低字节写入当前任务的 id 地址处。先是将用户虚拟地址映射到物理内存空间，最后在物理地址完成数据写入。
3. 查询调用次数（trace_request = 2）：返回当前任务对系统调用编号为 id 的累计调用次数（包含本次查询）。与 ```lab1``` 基本没有变动。

## 问答题

### 请列举 SV39 页表页表项的组成，描述其中的标志位有何作用？
SV39 页表项结构（64 位）：

| 位数      | 名称   | 含义                 |
| --------- | ------ | -------------------- |
| bit 0     | V      | 页表项是否有效       |
| bit 1     | R      | 可读                 |
| bit 2     | W      | 可写                 |
| bit 3     | X      | 可执行               |
| bit 4     | U      | 用户态是否可访问     |
| bit 5     | G      | 全局映射             |
| bit 6     | A      | 被访问过（硬件置位） |
| bit 7     | D      | 被修改（硬件置位）   |
| bit 8–9   | RSW    | 软件保留位           |
| bit 10–10 | PPN[0] | 三级物理页号         |
| bit 19-27 | PPN[1] | 二级物理页号         |
| bit 28–53 | PPN[2] | 一级物理页号         |
| bit 54–63 | -      | 保留                 |

### 缺页

#### 缺页导致的异常
1. ```Instruction Page Fault``` 
   执行指令时页未映射或不可执行
2. ```Load Page Fault```
   加载数据（读内存）时页未映射或不可读
3. ```Store/AMO Page Fault```
   存储数据（写内存）时页未映射或不可写

#### 发生缺页时相关重要寄存器的值
| 寄存器名 | 含义                   | 用途                                       |
| -------- | ---------------------- | ------------------------------------------ |
| sepc     | 保存引发异常的指令地址 | 用于异常返回时恢复指令执行                 |
| stval    | 存储导致异常的虚拟地址 | 缺页时为访问的虚地址                       |
| scause   | 指示异常原因           | 判断是 page fault 还是其他异常             |
| sstatus  | 包含当前 CPU 状态      | 可用于检查特权级等信息                     |
| satp     | 保存页表根地址         | 用于定位根页表的 PPN                       |
| sp/tp/gp | 等	通用寄存器          | 有时可用来判断是否是用户栈或全局数据区缺页 |

#### Lazy 策略的好处
1. 节省内存资源
   如果程序的一部分代码或数据从未被访问，那么这些页面就永远不会分配物理页，避免了浪费内存。例如 ```.text``` 段中某些函数永远不会调用，不需要为其分配物理页。
2. 加快程序启动速度
   启动进程时，OS 无需马上加载整个可执行文件的所有段（如 ```.text```, ```.data```, ```.bss```），只需设置页表中的占位信息，等待实际访问时再加载，从而让程序更快启动。
3. 支持按需加载和共享内存机制
   类似 ```.text``` 段可以多个进程共享一个物理页，只有在写入时再复制（写时复制，COW）。
4. 方便实现更高级的内存管理功能
   如匿名映射（mmap）、文件映射（memory-mapped file）、需求分页（demand paging）。
